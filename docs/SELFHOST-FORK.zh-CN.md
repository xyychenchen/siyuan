# 自建同步测试版

本分支基于 SiYuan 3.8.9，保留官方界面及本地优先的同步、加密和冲突处理机制。
修改仅允许 S3、WebDAV 和本地存储在没有思源账号/订阅时使用；官方云的订阅验证保持原样。
源码遵循原 AGPL-3.0-or-later 许可证，保留原作者声明。本项目不是官方发行版。

## 架构与使用

服务器运行本分支内核及网页界面，并提供独立的 WebDAV 或 S3 存储。
手机运行本分支构建的 Android App，本地保存工作空间，通过同一个存储同步。
浏览器编辑由服务器内核保存，再同步至存储；手机编辑由本地内核保存，再同步至存储。
存储里的加密同步仓库不是浏览器能直接打开的笔记工作空间。

两端在“设置 → 云端”选同一个自建 WebDAV/S3 地址、凭据和同步目录，并使用同一个数据仓库密钥。
第一次测试请使用空工作空间和空同步目录，验证完成后再导入真实笔记。
先在一端设置密钥并完成首次同步，再在另一端导入该密钥。保管密钥备份，服务端密码无法替代密钥。
不要把多个运行中的内核直接指向同一份工作空间文件夹。

手机离线时仍可编辑已经下载的笔记；恢复网络后按照思源现有同步周期同步。
“资源下载模式”选择全部下载可保留离线附件；按需下载时，未下载的附件离线无法访问。
同时修改同一篇笔记仍可能产生冲突，应保留冲突文档并检查合并结果。

## 云端构建

GitHub Actions 的 Self-hosted SiYuan test builds 工作流执行检查并生成：
- selfhost-ui：共享网页资源。
- selfhost-linux-amd64：Linux 测试内核。
- siyuan-selfhost-android-arm64-test：Android 8+、ARM64 测试 APK。

Android 壳固定为 siyuan-note/siyuan-android 的
9adea3ae243ea18c5a9c83ac1ed2394f582f643a，资源和内核来自当前 fork 提交。
构建脚本把版本号调整为对应内核版本，并使用官方 Debug 变体的独立包名
org.b3log.siyuan.debug，不覆盖官方 App。界面保持原样。
目前使用 CI 临时调试签名，后续构建不保证能覆盖安装；长期使用前需要固定私有签名。
下载构建产物时应记录 Actions 的提交 SHA，不能用官方自动更新替换此修改版。

## 当前验证边界

构建和回归测试通过不等于手机端到端同步通过。
正式交付前必须验证：两端互传、附件、离线修改后重连、错误凭据、重启持久化以及冲突文档。
本测试工作流只生成产物，不会改动现有 AWS 服务或已有数据。

前端类型、代码规范检查和同步设置相关 33 项回归测试已在开发环境通过。
扩展受影响测试包含 Electron 窗口用例，开发环境以 root 运行时受 Chromium 沙箱限制；
这部分改在普通用户的 GitHub Actions 虚拟显示环境执行，结果需以对应日志为准。
